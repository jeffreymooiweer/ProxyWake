# ProxyWake v4.2.7

## Summary

Maintenance release bundling the safe dependency and CI updates opened by Dependabot. No functional changes. Every backend dependency bump was verified against the full test suite (110 tests) and a live smoke test (CORS preflight, rate limiting, gunicorn boot) before inclusion.

## Changed

### Backend dependencies

| Package | From | To | Notes |
|---------|------|-----|-------|
| `cryptography` | `>=42.0.0` | `>=49.0.0` | Security |
| `Pillow` | `>=10.0.0` | `>=12.3.0` | Security (dev icon tooling) |
| `flask-cors` | `>=4.0.0` | `>=6.0.5` | Major; CORS preflight re-verified |
| `flask-limiter` | `>=3.5.0` | `>=4.1.1` | Major; rate limiting re-verified |
| `gunicorn` | `>=21.2.0` | `>=26.0.0` | Major; boot re-verified |

### CI actions

- `github/codeql-action` v3 → v4
- `docker/setup-qemu-action` v3 → v4
- `actions/setup-node` v4 → v6

## Not included

The frontend framework major bumps (React 19, `@mui/material` 9, `i18next` 26, `react-i18next` 17) were **held back**. They do not install cleanly on the current Create React App (`react-scripts` 5.0.1) toolchain — `npm install` fails on a peer-dependency conflict — and MUI 5 → 9 would require migrating the `Grid` API used throughout the UI. These need a dedicated migration and testing pass, not an automatic merge, and the app runs correctly on the current versions.

## Upgrade

```bash
docker pull jeffersonmouze/proxywake:4.2.7
```

Recreate the container with the same appdata path and environment variables.
